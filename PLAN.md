# Axeriel Svelte - Implementation Plan for Fully Typed Sanity Integration

## 🎯 Project Goals

This plan outlines the implementation strategy for creating a fully typed SvelteKit application that integrates seamlessly with Sanity CMS, featuring:

1. **Automatic Type Generation**: Types automatically inferred from Sanity Studio using their type codegen functionality
2. **GROQ Query Typing**: Direct type inference from GROQ queries
3. **Fully Typed Components**: All Svelte components typed based on Sanity schema with automatic updates
4. **Page Builder System**: Svelte pages generated by a page builder following Sanity schema (array of components)
5. **Static Routing**: All routes in the Svelte app are static

## 🔧 Technical Implementation Details

### Sanity Client Setup

```typescript
// apps/web/src/lib/sanity/client.ts
import { createClient } from "@sanity/client";
import type { SanityClient } from "@sanity/client";
import type { SanityTypes } from "./sanity.types";

export const sanityClient: SanityClient = createClient({
  projectId: import.meta.env.SANITY_PROJECT_ID,
  dataset: import.meta.env.SANITY_DATASET || "production",
  apiVersion: "2024-01-01",
  useCdn: import.meta.env.PROD,
});

export async function fetchPageBySlug(slug: string): Promise<SanityTypes.Page> {
  const query = `*[_type == "page" && slug.current == $slug][0]{
    ...,
    pageBuilder[]{
      ...,
      _type == "hero" => {
        "type": "hero",
        ...select(_type == "hero" => @)
      },
      // Other block types
    }
  }`;

  return sanityClient.fetch(query, { slug });
}
```

### Page Builder Component

```svelte
<!-- apps/web/src/lib/components/page-builder/PageBuilder.svelte -->
<script lang="ts">
  import type { SanityTypes } from '$lib/sanity/sanity.types';

  // Component registry
  const componentMap: Record<string, any> = {
    hero: () => import('./blocks/Hero.svelte'),
    cta: () => import('./blocks/CTA.svelte'),
    // Other block types
  };

  export let pageBuilder: SanityTypes.PageBuilderBlock[];
</script>

{#each pageBuilder as block}
  <svelte:component this={componentMap[block._type]} {...block} />
{/each}
```

### Static Route Generation

```javascript
// apps/web/src/routes/[slug]/+page.ts
import { fetchPageBySlug } from '$lib/sanity/client';
import type { PageLoad } from './$types';

export const load: PageLoad = async ({ params }) => {
  const page = await fetchPageBySlug(params.slug);
  return {
    page,
    // Proper TypeScript typing
  };
};
```
